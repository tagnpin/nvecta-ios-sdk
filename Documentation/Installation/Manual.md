# Manual Installation

| :bulb: We strongly recommend integrate the NVECTASDK / notifyvisitorsn SDK via [Swift Package Manager](../../README.md#recommended-swift-package-manager). However, if you are unable to do so you can integrate our `notifyvisitors` SDK manually using the instruction given below. |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

NVECTA iOS SDK can also be integrated manually by adding the distributed `notifyvisitors` XCFramework files directly to an Xcode project.

This installation method is intended for applications that do not use a dependency manager such as `Swift Package Manager` or `CocoaPods`.

---

## 1. Obtain the XCFramework

Download the required `notifyvisitors` iOS SDK `XCFramework` from the official website documentation using [Download iOS SDK](https://www.nvecta.com/docs/ios-integration#option-2-manual-integration) button link under the [Manual Integration](https://www.nvecta.com/docs/ios-integration#option-2-manual-integration) heading.

## 📊 What's Next?

Now you can refer to our official website documentation to proceed the remaining integration steps.
